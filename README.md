1. OVERVIEW
================================================================================

Tertiary SA is a free, registration-free platform designed to help students
explore higher education opportunities in South Africa. It provides a complete
directory of all 29 public universities and 1,490 registered colleges across
all 9 provinces, along with detailed course information, admission requirements,
and bursary opportunities.

The platform eliminates the need for multiple website visits by centralizing
all tertiary education information in one easy-to-use interface.

Statistics:
  • Universities: 29
  • Colleges: 1,490
  • Provinces: 9
  • Bursaries: 14+
  • Languages: 4 (English, Afrikaans, isiZulu, isiXhosa)
  • Total Institutions: 1,519

4. INSTALLATION
================================================================================

4.1 DIRECT DOWNLOAD
  1. Download the index.html file
  2. Save it to your computer
  3. Double-click to open in your browser

4.2 GIT CLONE
  git clone https://github.com/yourusername/tertiary-sa.git
  cd tertiary-sa

4.3 LOCAL DEVELOPMENT SERVER

  Using Python 3:
    python -m http.server 8000

  Using Node.js:
    npx serve

  Using PHP:
    php -S localhost:8000

  Then open http://localhost:8000 in your browser.



5. DEPLOYMENT
================================================================================

5.1 GITHUB PAGES (FREE)
  1. Create a GitHub repository
  2. Upload index.html
  3. Go to Settings → Pages
  4. Deploy from branch main
  5. Live at: https://yourusername.github.io/tertiary-sa

5.2 NETLIFY (FREE - DRAG & DROP)
  1. Sign up at netlify.com
  2. Drag and drop index.html
  3. Instant deployment at your-site.netlify.app

5.3 VERCEL (FREE)
  npm install -g vercel
  vercel

5.4 SURGE.SH (FREE)
  npm install -g surge
  surge index.html your-site.surge.sh

5.5 CUSTOM DOMAIN
  • GitHub Pages: Add CNAME file with your domain
  • Netlify: Configure custom domain in Settings
  • Update DNS settings accordingly
